# Prior knowledge: comfortable in Java, new to Spring

Stated at the start of the first session: comfortable reading and writing Java,
no Spring experience. Self-describes as a newbie, which refers to Spring and its
ecosystem rather than to the language.

**Implications for teaching.** Do not spend lesson budget on Java syntax,
collections, or generics. The genuinely new material is inversion of control,
annotations as configuration, auto-configuration, the build ecosystem (Maven
coordinates, transitive dependencies, BOM-managed versions), and the servlet
request path. Lessons should lean on Java knowledge as the bridge — "you know
what `new` does; here is why you stop calling it" — rather than re-teaching it.

**Evidence.** Self-reported, not yet demonstrated. Downgrade this record if a
future session shows the Java base is shakier than stated.
