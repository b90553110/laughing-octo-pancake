How this works

The teach skill lives in this repository at .claude/skills/teach/, so any Claude Code session opened on this repo — including from a phone — picks it up automatically.

Ask for a lesson with:

/teach how German case endings work

Claude writes the lesson into lessons/, links it from this page, and pushes. GitHub Pages redeploys within a minute or so, and the new lesson is listed above.
